# Streamlit Assignment

## Files Included

1. app_basic.py
   - Displays a title and greets the user.

2. app_discount.py
   - Calculates discounted price using a slider.

3. app_product_form.py
   - Takes product details from the sidebar and displays them.

4. app_dashboard.py
   - Shows monthly sales data and a bar chart.

## How to Run

Install Streamlit:

```bash
pip install streamlit

## Run the command by passing the file name
streamlit run app_basic.py
